# Data

**Online Retail II**, UCI Machine Learning Repository.

> Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository.
> https://doi.org/10.24432/C5CG6D — licence CC BY 4.0

All transactions of a UK-based online gift-ware retailer (many customers are wholesalers),
1 Dec 2009 – 9 Dec 2011, 1,067,371 lines.

## Get the file
1. https://archive.ics.uci.edu/dataset/502/online+retail+ii → **Download**
2. Unzip; put `online_retail_II.xlsx` in `data/raw/`
3. `python run_all.py`

The raw file (43.5 MB) and the basket-line table (~62 MB) are not committed;
`orders.csv`, `product.csv`, `customer_rfm.csv` and all report outputs are.
